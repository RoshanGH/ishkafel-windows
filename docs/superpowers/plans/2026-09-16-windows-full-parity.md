# Ishkafel Windows 全功能对齐实施计划

> 依据：`docs/windows-port/02-功能对齐清单.md`、`05-平台耦合清单.md`、`06-移植建议.md`、`07-对齐怎么守.md`、已批准的 Windows 设计规范。  
> 原则：测试先行；每个波次完成后执行定向测试、静态分析、全量测试、Release 构建和真实应用检查。

## 波次 1：Windows 平台契约

1. 为 Known Folder、临时目录、Windows 文件名与用户目录建立失败测试。
2. 让 GUI/CLI/Agent Skill 共用 `PlatformPaths`，移除 `HOME/Movies/Desktop` 散落实现。
3. 增加持久文件日志与滚动策略，保留 CLI stderr。
4. 清理 `brew`、Mac“终端”等 Windows 错误指引。
5. 实现并测试 Windows 单实例与唤醒既有窗口。

## 波次 2：剪映 Windows 原生草稿

1. 为 Windows 平台字段、路径分隔、字体、封面路径建立失败测试。
2. 将草稿构造参数化为 Mac/Windows 平台配置，Mac 行为保持不变。
3. 用 Windows 剪映真实安装位置写入、打开、保存并复读草稿。
4. 固化一份匿名化兼容样本与自动结构校验。

## 波次 3：媒体与字幕一致性

1. 建立固定视频、声音、字幕、字体测试夹具和内容指纹。
2. 比较 Windows helper renderer 与 Mac 参考输出的逐帧像素。
3. 验证拼接、倍速、替换、TTS、BGM、音频拆分的时长、声道与同步。
4. 覆盖取消、失败重试、断点续跑、磁盘不足和非 ASCII 路径。

## 波次 4：全产品流程与 UI

1. 为 28 个基线状态建立可重复导航与 Windows 截图。
2. 逐状态对比布局、层级、文案、焦点、滚动、快捷键和系统壳。
3. 真实走完自动分析、空白时间线、脚本成片三条生产线。
4. 验证任务复制隔离、全局标签组、设置、更新、账号和帮助入口。

## 波次 5：CLI、分发、性能与持续同步

1. 逐一验证 28 条 CLI 命令的退出码、JSON、写锁、视觉模式和 GUI 同库并发。
2. 验证 ZIP/MSIX 的安装、升级、卸载、更新回滚和工具许可。
3. 建立 1080p/4K 的导入、预览、导出、内存与长时间稳定性基线。
4. 演练 Mac `upstream` 新提交进入同步 PR，要求 Windows 全门禁通过。

## 最终完成门槛

只有 `docs/windows-port/09-Windows功能对齐审计.md` 的验收账本全部打勾，且证据可复现，才可以合并、推送并宣称项目完成。
