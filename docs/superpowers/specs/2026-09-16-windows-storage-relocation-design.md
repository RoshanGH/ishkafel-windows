# Windows 可配置存储与 D 盘迁移设计

## 背景与目标

Ishkafel Windows 当前的源码、便携应用、验收数据和导出交付物主要位于系统盘，桌面同时存在正式入口和真实测试入口。目标是让 Windows 版在软件内配置数据/素材目录与默认导出目录，并把本机 Ishkafel 的大体积项目物料安全迁移到 `D:\Ishkafel`。桌面最终只保留一个正式的 `Ishkafel` 快捷方式。

## 目录布局

```text
D:\Ishkafel\
├── App\                 # 当前可运行的便携版应用
├── Source\              # Windows 独立仓库
├── UserData\            # 任务、数据库、模型与应用日志
├── Cache\               # 构建和工具缓存
├── Media\
│   ├── Imports\         # 用户导入的源视频
│   └── Exports\         # 软件默认导出位置
├── Deliverables\        # 安装包、报告、截图与验收成品
└── Tools\               # 项目专用工具（按安全边界迁移）
```

Windows 注册表 `HKCU\Software\RoshanGH\Ishkafel` 保存两个用户级设置：

- `StorageRoot`：数据根目录，例如 `D:\Ishkafel\UserData`。
- `ExportRoot`：默认导出目录，例如 `D:\Ishkafel\Media\Exports`。

路径选择本身不写入 C 盘配置文件。Windows、Flutter 和依赖库不可避免的少量系统注册、临时文件不属于项目物料，也不承诺从系统盘消失。

## 路径优先级与兼容性

路径解析保持现有自动化和命令行兼容：

1. 既有环境变量 `ISHKAFEL_DATA_DIR` / `ISHKAFEL_LOG_DIR` 具有最高优先级。
2. 新环境变量 `ISHKAFEL_STORAGE_ROOT` / `ISHKAFEL_EXPORT_DIR` 次之，供部署和自动化使用。
3. Windows 注册表中的用户设置再次之。
4. 未配置时完全保留当前平台默认行为。

当使用 `StorageRoot` 时，任务数据位于根目录下的 `data`，日志位于 `logs`。CLI 与 GUI 必须解析到同一数据目录。非 Windows 平台不读取注册表，避免影响上游 Mac 版本。

## 设置界面

设置页增加“存储位置”区块，显示并允许分别选择：

- 数据与素材位置；
- 默认导出位置。

导出对话框仍允许单次选择其他目录；如果任务没有上一次导出位置，则优先使用全局默认导出目录。

更改数据位置会执行安全迁移：

1. 验证目标不是源目录、也不嵌套在源目录中；
2. 复制到目标目录；
3. 对每个文件核对相对路径、字节数和 SHA-256；
4. 仅在完整校验成功后写入注册表；
5. 提示重启应用；
6. 软件不自动删除旧目录。旧目录由本次人工验收在新位置启动成功后精确删除。

迁移失败时保持旧配置和旧数据不变，并显示可操作的错误信息。

## 本机迁移与路径修复

本次迁移按“停止应用 → 复制 → 校验 → 切换注册表 → 从 D 盘启动 → 真实打开和导出 → 删除精确 C 盘源目录”的顺序执行。真实任务中指向桌面源视频和旧导出文件的绝对路径，在移动后同步更新为 D 盘路径，并在应用内重新打开验证。

GitHub 仍使用 Windows 独立仓库 `RoshanGH/ishkafel-windows`，保留 Mac 仓库为 `upstream`，以便后续跟随更新。D 盘源码克隆必须保留这两个远程仓库和当前提交历史。

## 安全边界

- 不递归删除用户主目录、Codex 根目录或整个 AppData。
- 只删除已列明、已复制并逐文件校验通过的 Ishkafel 专用目录。
- 凭据文件不打印、不提交 Git，只在受控目录中移动并保留访问控制。
- 全局 MiaoA 登录状态、Windows 注册表、Desktop 快捷方式及系统组件可继续占用少量 C 盘空间；它们不是可迁移的项目大文件。

## 验收标准

- 路径解析和注册表存取有单元测试，非 Windows 回退不退化。
- 安全迁移有成功、校验失败、非法嵌套路径测试。
- 设置页可以选择和保存两类目录，导出默认目录生效。
- 完整 Flutter 测试与静态分析通过。
- D 盘应用可以打开真实任务、播放真实视频并完成一次真实导出。
- 桌面只保留一个 `Ishkafel` 快捷方式并指向 D 盘应用。
- 指定的 C 盘源码、应用、验收数据和交付物在最终校验后删除。
