# 无管理界面的故障报告

用户已批准：客户端自动收集日志和系统信息，一键提交，描述和截图选填；API + 数据库供 Agent 查询，不开发管理页面。部署到公司服务器 47.119.175.47，使用已有 MySQL，独立库与受限账号；无域名，使用 IP SAN 证书和客户端专用 CA 信任。

## 首个交付范围

- Flutter 设置页及全局反馈入口，采集有限量的滚动日志、版本、OS、CPU、显卡/驱动、内存、磁盘余量和进程运行记录。
- 报告先原子保存到所选数据目录 diagnostics/outbox，再上传；失败保留原报告，可手动重传，重传不生成重复报告。最多保留 20 份待传报告，满时拒绝新建并明确提示。
- 可选描述（界面最多 500 字，API 最多 2000 UTF-8 字节）和 PNG/JPEG 截图（4 MiB 内），不默认采集屏幕，不上传视频文件、配置文件或环境变量全集。近期日志可能包含任务上下文片段，提交前明确告知。
- 文本在本地移除凭据、JWT、Authorization、URL 查询串和本机用户名路径；已载入的 AI 与更新凭据须按原值移除。截图由用户主动选择，不能保证图像中的敏感文字被脱敏。
- API：POST /v1/reports；GET /v1/reports?after=0&limit=50&version=&kind=；GET /v1/reports/{id}；PATCH /v1/reports/{id} 写分析状态与修复版本。提交、读取、处理权限使用三个不同 token。
- 服务端使用 Python WSGI + MySQL + Waitress；SQLite 仅供契约测试。附件嵌入报告，gzip 压缩存 MySQL BLOB，同时保存索引和处理状态。每请求最多 8 MiB，压缩正文总额最多 2 GiB，过期报告定期清理，服务器事务提交成功再确认。
- Windows 无响应检测和异常退出证据作为本地独立监测记录补充；不在首版自动采集包含凭据的内存 dump，不声称仅凭日志能够替代 native crash 堆栈。独立采集入口可在主窗口卡住时使用。
- 上线需 HTTPS、实际公司服务器、反向代理限流、三个不同 token；不能用本机地址发布给同事。读取/处理 token 只留在受限服务器文件及维护者私有目录，员工客户端只含提交 token。

## 验收

未填描述/截图能成功提交；报告含日志与硬件；凭据不进入文本；失败保留，重传幂等；上传 token 不能查询或更新；大包/畸形附件拒绝；分页按服务端序号稳定查询；真机 Release 中点击提交，本地 API 可读到相同报告编号。
